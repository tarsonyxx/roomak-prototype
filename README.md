>It is a working prototype built for the sake of research, not a production system for UMak. Room details, schedules and reports are sample data for demonstration unless verified separately.

## Features

- **Floor Plan** — Interactive map of Building 2, the Bridgeway and Building 3 (floors 2 to 4). Drag to move, pinch or use the buttons to zoom.
- **Availability by Time** — Pick a floor, day and time range, and every room is colored: green is available, yellow is unavailable or under maintenance, red is in use, and grey rooms cannot be reserved.
- **Room Information** — Tap a room to see its photo, capacity, facilities, current availability and its schedule for each day.
- **Room Requests** — Request a room for one time or on a recurring schedule, with a message to the scheduler. Rooms that are in use or not reservable are blocked.
- **Room Reports** — View issues already reported for a room and report a new one.
- **First-Time Tips** — A short guided tour for new users. The **?** button replays it.
- **Mobile Friendly** — Built phone-first, with the room panel covering the map on small screens.

Still planned: role-based views (teacher, scheduler, student), shared data storage, and real accounts.

Features may be simplified or simulated to fit the prototype's development timeline.

## Technology

- HTML for page structure
- CSS for styling and layout (colors are easy to change in one block in `css/base.css`)
- JavaScript for the floor plan, availability, requests and reports
- Browser `localStorage` for saving requests, reports and tips on the user's own device

No frameworks or build tools are used. The floor plan is generated by JavaScript from the room data in `data/rooms.js`, and class schedules are in `data/schedules.js`.

The prototype does not provide shared, multi-user data storage or real-time room occupancy information. Requests and reports are saved only in the browser they were made in, and nothing is sent to a server.

## How to Run Locally

1. Clone or download this repository.
2. Open the folder in VS Code and install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Log in with the demo account: username `demo`, password `1234`.

The files can also be hosted on any static host, such as GitHub Pages.

## Project Status
